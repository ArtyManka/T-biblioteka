# T-Библиотека

Консольное приложение для управления личной библиотекой книг на C#.

# Возможности:
- Добавление книг
- Просмотр с сортировкой и фильтрами
- Поиск по ключевым словам
- Отметка книг как прочитанные / избранные
- Удаление книг
- Сохранение и загрузка данных из JSON-файла

# Требования:
- .NET 6.0 или выше

# Как запустить:
1. Откройте командную строку в папке проекта
2. Выполните: `dotnet run`

# Использование:
Следуйте меню в консоли для управления библиотекой.
