# T-Библиотека

Консольное приложение для управления личной библиотекой книг на C#.

# Возможности:
- Добавление книг
- Просмотр с сортировкой и фильтрами
- Поиск по ключевым словам
- Отметка книг как прочитанные / избранные
- Удаление книг
- Сохранение и загрузка данных из JSON-файла

# Требования:
- .NET 6.0 или выше

# Как запустить:
1. Найдитек желтую иконку с именем "Т-библиотека" (T-biblioteka\bin\Debug\net10.0\Т-библиотека.exe).
2. Щелкните по ней 2 раза.

# Использование:
Следуйте меню в консоли для управления библиотекой.

# Как загрузить свою библиотеку:
1. Создать файл books.json в библиотеке (или вручную при наличии опыта).
2. Переместить файл books.json в папку T-biblioteka\bin\Debug\net10.0\.
3. Запустить библиотеку
4. В меню нажать 9 (Загрузить библиотеку)

# Если нашли ошибку:
1. Загуглите
2. Спросите DeepSeek или другую ИИ

#Если нашли баг:
1. Вспомните, что вы сделали, после чего появился баг.
2. Посторайтесь не делать этого.
